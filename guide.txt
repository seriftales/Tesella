terminalde şu komutu çalıştırarak ana kütüphaneyi ve resim, font, ses eklentilerini kur:

sudo apt install libsdl2-dev libsdl2-image-dev libsdl2-ttf-dev libsdl2-mixer-dev


Terminalde kök dizinde (~/Tesella) olduğunu varsayarak sırasıyla şu komutları girmelisin:

cd build
cmake ..
make
./tesella


imgui kurulum 

mkdir -p vendor/imgui
git clone -b docking https://github.com/ocornut/imgui.git temp_imgui
cp temp_imgui/*.h temp_imgui/*.cpp vendor/imgui/
cp temp_imgui/backends/imgui_impl_sdl2.* temp_imgui/backends/imgui_impl_sdlrenderer2.* vendor/imgui/
rm -rf temp_imgui
